# LATENCY-M1 execution contract

Scope: change only the latency benchmark and its guards. Model source and existing
training configs remain byte-identical to base `0ca61bc35ad68bd79b86103b54e470445cbab07f`.
No checkpoint, embedding or test input is used. No new latency threshold is set.

Input: an explicitly supplied validation JSON list, pinned by its raw SHA256.
Read each row only to obtain `len(row['history'])`; require 2520 rows and lengths
1..50. Report source histogram, raw hash and ordered-length hash. Feature values
remain synthetic; only the length distribution is real. No data path is inferred.

Formal invocation (run once per device, under the separately reviewed detached
launcher; record deployed commit and this script's reported SHA256):

```sh
PYTHONPATH=src python scripts/seqm1_latency_bench.py \
  --device cpu --lengths-json "$VALIDATION_JSON" --lengths-sha "$VALIDATION_SHA"
PYTHONPATH=src python scripts/seqm1_latency_bench.py \
  --device cuda --lengths-json "$VALIDATION_JSON" --lengths-sha "$VALIDATION_SHA"
```

Formal mode locks catalog120416, mean arm, seed7, batch512, warmup50,
timed1000, validation2520. `--fixture-mode` explicitly marks tiny tests non-formal.
Both anchor and mean replay identical synthetic tensors. Largest-remainder
allocation of the empirical histogram plus seeded shuffle determines each mode's
length schedule. Online uses each actual length; offline is padded to width50,
as in the existing batch export. One input batch is resident at a time. CPU is
single-threaded. Input generation, hashing and transfer precede timing; CUDA is
synchronized before and after every tower call. Each mode reports its warmup and
timed histogram, actual call/query counts, replay-input hash, all raw ms/query,
and nearest-rank mean/p50/p95/p99 (mean uses the arithmetic mean).

A separate single export pass traverses all 2520 source lengths in original order,
with batches512 and a final472; report the query-weighted elapsed mean and 5 calls.
It is distinct from the 1000-call offline distribution measurement. It follows the
preceding warmed measurements, with synthetic values and fixed width50.

Stop on source hash/count/range mismatch, invalid formal parameters or unavailable
CUDA. The parent owns review, public scan, push, deployment, resource admission,
server runs and experiment_log evidence. No P anchor switch is performed here;
Kiro must first check the completed report's measurement scope.
