## 2026-10-18 深夜（续三）：G 线 SID 结构实验冻结（48×48×48）；更正 Kiro 口头提出的 64³（Kiro，**Claude Opus 5**）

本节为该实验的冻结内容，执行者据此落卡（新文件 `docs/superpowers/specs/2026-10-18-sid-structure-matched-card.md`），只抄不增即视为 Kiro 确认冻结。名额按「有边界的常设授权」计 3 个 A1 训练加 3 个 verify。

1. **更正：不采用 64×64×64**。Kiro 在对话中口头提议 64³，算错了第 3 层。按 BHKM 的 `k = min(branching, len)` 逐层核算：

   | 结构 | 第 1 层利用率 | 第 2 层 | 第 3 层 | 结论 |
   |---|---|---|---|---|
   | 256×256×256（现行 C1′） | 100% | 100% | **0.4%** | 第 3 层空置，与实测 0.78% 一致 |
   | 64×64×64 | 100% | 100% | **45.3%** | **过不了利用率 ≥80% 门禁** |
   | **48×48×48** | 100% | 100% | **100%** | 三层全部承担实质划分 |
   | 50×50×50 | 100% | 100% | 96.0% | 次优备选，不用 |

   该核算模型在现行结构上复现了实测的第 3 层近乎空置（算 0.4% / 实测 0.78%），因此可信。**冻结为 48×48×48。**
2. **唯一科学变量 = SID 的分叉与深度匹配**。输入向量**固定为已验收的 C1′ 共现向量**（与当前 G anchor 同一来源、同一 SHA），不换输入、不重训 SGNS。BHKM 算法、fit seed 42、max_iter、确定性 suffix 规则逐字沿用现行 C1′ bundle 的拟合配置，只改 `branching=48`、`depth=3`。
3. **容量与碰撞**：48³ = 110,592 < 120,415，叶平均约 1.09 个物品，少量叶会有并列，由既有 suffix 规则处理。须报告：叶规模分布、最大叶、碰撞物品数与碰撞对数。**不得**为消除碰撞而改 suffix 规则或扩容。
4. **词表与合同**：语义码词表由 256×3 的规模变为 48×3，加 suffix 与特殊 token，总词表与 771 不同。登记为**新 schema、新版本名**，不冒用 `COLL_C1_B256D3_S42` 的身份，不改旧入口白名单。SID 仍为三位语义码加规范 suffix 的 `[N,4]`。
5. **门禁**：H1–H6 / R1–R4 按旧 GTOK-01 原文，**一字不放宽**。其中利用率 ≥80% 的门禁对三层分别适用——这正是本实验的设计目标之一，若某层未达 80% 即 FIT_FAILED，不调参、不放宽、不占训练名额。
6. **下游训练与判定**：A1 架构，history / features / catalog / query / split / 训练预算 / selection / beam 100 / 温度逐字段沿用当前 G anchor 的已验收配置，除 SID 身份与 schema 必需字段外不改。
   - seed 42 / 2024 / 2025 **三个无条件全跑**，不做 s42 筛选；对照为 **A1 + 共现向量 SID 同 seed（388 / 376 / 384）**，不重训对照。
   - 有效条件沿 decision_log 2026-10-15 16:5x 第 1 条三条：三训练 succeeded 且三 verify 直接 verified；三 seed 均值 Δhits ≥ 6；至少 2 个 seed Δhits ≥ 6。
   - **不移用**其它卡的阈值（T3 的 254、S1 的 260），**不自写**「388+6」。满足三条只提交 Kiro 裁决是否换 G anchor，不自动换。
7. **测量口径的重要限制（必须写进卡与报告）**：前缀准确率**不可跨分叉直接比较**。256 叉下「第 1 位命中」与 48 叉下「第 1 位命中」的粒度不同（前者每码约 470 个物品、后者约 2509 个），数值差异部分来自粒度而非模型能力。
   - 主判据只用 **item 级 hits**（分母 2520，in-catalog 1897 与 OOV 623 分列）。
   - 前缀准确率只作描述，并须同时报告每层每码的平均物品数，供读者自行折算。
   - 另报热度分档的 Δhits（沿 S0 的 train-only 分档与原分母），用于检验「第 2 层瓶颈」假设是否被缓解。
8. **机制假设（预先写死，便于事后判断是否被支持）**：若该结构有效，预期增益主要来自**头部与中段**，且前 2 位前缀的折算准确率相对现行结构上升。若增益为正但前缀折算准确率未上升，则写「增益来源未定」，不得归因到层级划分。
9. **与 S2 的关系**：S2 保持 256×3 不变、照原样跑完；两卡各自独立对照同一 G anchor，不交叉、不合并、不互为对照。若两者都有效，不在卡内选赢家，交 Kiro。
10. **S2 的一处连带提醒**（不改 S2 冻结内容）：S2 的 LETTER 式 tokenizer 同样是 3 层 256 叉，因此它也继承了第 3 层近乎空置这一结构缺陷。S2 若无效，**不能排除**「缺陷在结构而非可学习性」这一替代解释。该限制须写入 S2 的报告。
