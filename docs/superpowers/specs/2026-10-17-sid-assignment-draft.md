# 新视频 SID 分配设计草稿（SID 全量规模基准，S4）

状态：DRAFT，只出设计，不执行分配、改旧 bundle 或触发训练。依据 SID-FIX 卡 §6。

已有 SID 映射保持不可变。新视频必须带独立 catalog/version，先经过相同内容输入合同与可复现的向量变换，再分配；不得把新视频加入已有 validation 结果的候选集并继续沿用旧指标。

对于 BHKM，拟议的新格式须保存每个节点最终中心、距离空间、tie-break 和脚本/source hash。旧实现只保存节点大小/目标等信息，不能假装旧 bundle 已能按中心分配。新视频沿固定中心逐层选最近孩子，平手按码排序；这种在线路由不保证原容量均衡，须单列增量负载分布，不能声称通过原拟合 B1。是否重拟合、何时新开版本由 Kiro 另立卡，不修改既有门禁。

叶内 suffix 拟用持久、只增不改的分配账本：按唯一 item ID 去重，在同一版本锁内分配未使用 suffix，禁止复用已删除 item 的号码；并发提交须原子去重。新叶最大 suffix 可能超出旧模型词表，遇此情况标为不支持并停在版本规划，不能截断、取模或静默扩大词表。旧 catalog 中不存在的 item 继续按原 OOV 口径报告。

对于 RQ-VAE，拟议的离线分配需冻结 encoder/codebooks 与量化算术；读取任何既有 checkpoint 均须相应授权。当前只讨论合同，不加载权重。协同向量 SID 还须分别定义“无共现事件”和“无 P supported”回退；不得把新物品无信号解释为已有实验已验证的在线能力。

流式根节点基准只验证有界内存下的一次遍历，尚无三层均衡、完整 suffix 或在线分配正确性证据。不得将其结果外推成上述方案已实现或可上线。
